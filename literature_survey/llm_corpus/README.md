# LLM-readable analog circuit literature corpus

Contains 63 page-marked Markdown documents and 1062 retrieval chunks. Each document has provenance fields; chunks carry source URLs and page numbers. Use `manifest.jsonl` for document discovery and `chunks.jsonl` for retrieval. Verify formulas, figures, and numerical claims in the original PDF before reuse. Run `python build_llm_corpus.py` after changing PDFs or index metadata.
