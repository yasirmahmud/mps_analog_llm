# MPS Analog LLM

Research repository on **Large Language Models (LLMs) and Multi-Agent AI Systems for Analog and Mixed-Signal Circuit Design**, prepared for Monolithic Power Systems (MPS) and collaborative research.

## Repository Contents

- [**`literature_survey/`**](literature_survey/): Curated literature survey package containing:
  - [**`papers/`**](literature_survey/papers/): 63 verified full-text academic research papers in PDF format (2024–2026).
  - [**`llm_corpus/`**](literature_survey/llm_corpus/): Machine-readable text corpus with 63 page-marked Markdown conversions (`documents/`), metadata manifest (`manifest.jsonl`), and 1,062 retrieval passages (`chunks.jsonl`) for RAG.
  - [**`index.csv`**](literature_survey/index.csv) & [**`index.json`**](literature_survey/index.json): Structured catalogs with paper titles, authors, venues, source/PDF URLs, file sizes, categories, and SHA-256 checksums.
  - [**`README.md`**](literature_survey/README.md): Categorized paper index organized across 8 core taxonomies with direct links to local PDFs.
  - [**`literature_survey.md`**](literature_survey/literature_survey.md): Comprehensive literature survey report and proposed 4-stage MPS agent pilot plan.
  - [**`not_downloaded.md`**](literature_survey/not_downloaded.md): Context on identified works without an open PDF endpoint.
